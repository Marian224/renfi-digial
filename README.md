# RENFI DIGITAL

Landing page agencji RENFI DIGITAL — React + Vite + Tailwind CSS + Motion.

## Uruchomienie

```bash
npm install
npm run dev
```

Następnie otwórz adres pokazany przez Vite, zwykle:

http://localhost:5173

## Build produkcyjny

```bash
npm run build
npm run preview
```

## Co dalej
